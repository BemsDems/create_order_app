# Stock Forecast App (StockAI RU)

Одностраничное веб-приложение (React JSX + Tailwind) для прогнозирования акций российского фондового рынка.

## Структура

- `index.html` — полностью автономный SPA: React 18 UMD + Babel Standalone + Tailwind CDN. Все данные мокаются клиентским seeded-RNG, внешних API нет.

## Секции

1. **Hero** — анимированные частицы на canvas, градиентный заголовок, кнопка «Начать анализ».
2. **Каталог** — 54 тикера Мосбиржи, поиск, фильтры по 14 секторам, glassmorphism-карточки с ценой/дневным изменением.
3. **Прогноз** — выбор горизонта (5/10/30/60/120/240/360 дней), анимация «расчёта» 6–8 сек, вердикт (рост/снижение/нейтрально), счётчик вероятности, 6 факторов влияния, AUC модели, дисклеймер.
4. **О проекте** — методология (TCN neural network), ключевые метрики.

## Как запустить локально

Никакой сборки не требуется, откройте `index.html` напрямую в браузере или через любой статический сервер:

```bash
cd stock-forecast-app
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Дизайн-токены

- Тёмная палитра: `#0a0f1a` (фон), `#7c3aed` (фиолетовый), `#06b6d4` (бирюзовый)
- Шрифты: Manrope (UI) + JetBrains Mono (цифры/тикеры)
- Glassmorphism: `rgba(255,255,255,0.04–0.08)` + `backdrop-filter: blur(16–24px)`
- Анимации: только CSS transitions / keyframes, без framer-motion

## Дисклеймер

Прогнозы носят информационный характер и не являются инвестиционной рекомендацией.
